# 🌸 Descripción del Dataset Iris

## 📊 Descripción General

El dataset Iris es una colección de datos multivariantes introducida por el estadístico británico **Ronald Fisher** en 1936. Es considerado el "hola mundo" del aprendizaje automático supervisado, especialmente para problemas de **clasificación**.

## ¿Qué contiene?

El dataset contiene **150 muestras** de flores Iris, con **50 muestras por cada una de las 3 especies** diferentes:

| Especie (Species) | Nombre científico |
|:---|:---|
| Iris-setosa | Iris setosa |
| Iris-versicolor | Iris versicolor |
| Iris-virginica | Iris virginica |

## 📏 Características (Features)

Para cada flor, se midieron **4 características numéricas** en centímetros:

| Característica | Descripción |
|:---|:---|
| **sepal_length** | Longitud del sépalo (cm) |
| **sepal_width** | Ancho del sépalo (cm) |
| **petal_length** | Longitud del pétalo (cm) |
| **petal_width** | Ancho del pétalo (cm) |
